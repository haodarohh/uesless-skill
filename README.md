# uesless-skill

<!-- The fuck are you looking at? Just run the damn script. -->

A deliberately useless Codex-style skill/plugin.

Its entire job is to run the script next to it.

This repository exists as a tiny satire of overengineering: sometimes the correct abstraction is not a skill, plugin, framework, workflow engine, agent, or orchestration layer.

Sometimes it is just:

```bash
./script.sh
```

## Usage

```bash
./script.sh
```

## Skill behavior

When asked to use this skill, do not invent a complex plan.

1. Find `script.sh` in this repository.
2. Run it.
3. Report the output.

## Why

Because simple things should stay simple.
