### Purpose

This skill exists to demonstrate that not every action requires an AI workflow abstraction.

### Instructions

When this repository is used as a skill/plugin:

- Do not create additional planning layers.
- Do not generate orchestration logic.
- Do not build another framework.
- Run `./script.sh`.
- Return the result.

### Anti-patterns

Avoid:

- Multi-agent coordination
- Dynamic task routing
- YAML workflow generation
- Prompt chains
- "AI-native execution fabric"
- Reinventing bash with more tokens
